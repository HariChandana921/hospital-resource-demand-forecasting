# Data

This folder contains the sample data used for the hospital resource demand forecasting project.

The dataset used in this repository is synthetic and is designed to represent hospital operational patterns such as admissions, discharges, bed occupancy, staffing, and procedure volumes.

No patient records, employer datasets, or confidential healthcare information are included.

## Main Fields

- `date` - Date of the observation
- `hospital_id` - Synthetic hospital identifier
- `department` - Hospital department
- `admissions` - Number of patient admissions
- `discharges` - Number of patient discharges
- `available_beds` - Total beds available
- `occupied_beds` - Beds occupied
- `staff_count` - Staff scheduled for the period
- `procedure_count` - Number of procedures performed
